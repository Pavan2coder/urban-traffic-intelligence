# AI-Powered Urban Traffic Intelligence Platform

## Problem Statement
Urban traffic congestion causes time loss, fuel waste, and inefficient mobility.
Existing systems are mostly reactive and lack predictive intelligence.

## Objective
To build a web-based AI-powered platform that predicts traffic congestion
and provides optimized routes using machine learning and graph algorithms.

## Tech Stack
- Frontend: Streamlit
- Backend: FastAPI (planned)
- ML: Scikit-learn (planned)
- Algorithms: Dijkstra
- DevOps: Docker (planned)
- Cloud: Google Cloud Run (planned)
